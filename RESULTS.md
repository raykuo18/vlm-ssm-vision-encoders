# Results

This release keeps the paper-facing tables static and venue-neutral.

Available files:

- `results/matched_224.csv`
- `results/matched_224.md`
- `results/dense_objective.csv`
- `results/dense_objective.md`
- `results/released_model_zoo.csv`
- `results/released_model_zoo.md`

`matched_224` covers the released 224-resolution classification models.

`dense_objective` covers the released dense-task adapted models.

`released_model_zoo` is the canonical public summary table for the eight checkpoint ids shipped in this release.
